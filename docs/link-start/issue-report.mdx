# 我有問題
如果你在宿舍的網路設備不怎麼聽話，可以開工單請網管來幫你馴服他們。網管有受過訓練能夠安撫情緒不穩定但是可教化的網路設備，當網管正在和設備搏鬥的時候，請避免拍打、餵食、催促，~~這可能會導致需要另一個人來安撫網管，讓事情變得更複雜~~，但閒聊是可以的^_^。

開單請[點我](https://sdsc-network.zite.so)，或是掃描以下的 QR code。

![issue-report-qr.](/img/issue-report-qr.webp)
:::danger
Dunning-Kruger effect 告訴我們，能力欠缺的人總有一種虛幻的自我優越感，錯誤地認為自己比真實情況更加優秀，通常以為自己能輕鬆駕馭的人到後面都很容易把事情弄的很糟。請相信擁有國際網管執照的網管勝過你自己那奇怪的直覺。
:::
## 開單流程
填完你的問題，你會馬上收到一封信，如果過了 10 分鐘你沒收到信，你應該依序檢查垃圾郵件、你填寫的電子郵件位址最後再考慮重填表單。

這裡理論上要有一張開單流程圖，但...

![打造未來的中興](/img/build-future.webp)

之後所有的線上訊息如果需要線上溝通，網管會直接在這封 email 回覆，要記得看信，也要記得回，愛你。
### 收到工單確認信
接下來，網管看到你的工單後可能會做出兩種反應：

1. 直接到你房間敲門
2. 寄信和你說大概什麼時候出現

如果剛開學很不幸的有很多人在排隊，那你可能還會收到一封罐頭訊息請你耐心等待。通常不會把你擱在旁邊超過一週，如果有這種情況，請在工單的信件底下直接回覆告訴我這個問題還沒被解決詢問隊列進度。


## 結單
被結單後，你也會收到一封罐頭信告訴你結單了。

- 你的問題被解決
- 不小心被人工標記為已解決
