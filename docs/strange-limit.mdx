# 有趣的限制
這邊彙整了我一年級就很好奇的問題，好在我當了網管看了後台之後就知道為什麼了，如果你有和我一樣的問題，請看XD。
## 為什麼學校要限制宿舍網路流量？
~~學校不是很喜歡大家沒日沒夜的空間超大的遊戲~~。

網路頻寬要錢，你就付這點住宿費而已。
## 為什麼一個網路孔那麼多麻煩的設定？
因為現在用的偉大的 [Curelan PMS-5000U](https://www.curelan.com/02products/IPMS_introduce_20100820.pdf)，這台機器出廠年份大概比你老，如果你很厲害挖出 CVE，那可能學校就會更新成支援 802.1X＋RADIUS/NAC 的交換器（？
## 為什麼我只能上系統改一次卡號？
因為管理系統直接限制你不能改太多次，我拿到的權限也沒辦法關掉這個限制。告訴你一個小秘密，如果更換 IP 後你當天的流量會重置，也就是說如果在超流就上來改卡號（你只要在路由器上啟用自訂 Mac address ）就可以有無限流量！

流量這可不是免費的，於是學校現在都啟用了這個設定，一旦你改卡號超過兩次，你就得聯絡網管。
